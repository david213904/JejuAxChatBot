# suktae — 제주AX단 AI 컨설턴트 (위젯 방식)

제주AX단 홈페이지 방문자 중 AI를 써 봤지만 막힌 사람에게 막힌 지점을 짚고 알맞은 교육을 안내하는 챗봇입니다.
이 폴더는 저장소 루트의 Next.js 뼈대(`app/`, `lib/`, `data/`)와 **섞이지 않도록 따로 둔 작업 공간**입니다.

## 폴더
| 경로 | 내용 | 담당 |
|---|---|---|
| `frontend/` | 챗봇 위젯(바닐라 JS/CSS)과 데모 화면 | 프론트 담당 |
| `backend/` | AI 호출 서버 함수 자리, 환경변수 틀, 가짜 응답(mock) | 백엔드 담당 |
| `data/` | 분류 체계(`taxonomy.json`), 교육 목록(`courses.json`) | 공용 (수정 전에 알림) |
| `docs/` | 기획서, 제안서 PPT, 팀 공유 문서, 개발 명세 | 공용 |

개발 명세는 `docs/개발명세/`의 세 문서(공통 기준, 프론트, 백엔드)를 먼저 읽으세요.

## 현재 상태
- `frontend/widget/`: 규칙 기반 진단 샘플이 동작합니다. 교육 4건과 질문은 아직 `widget.js` 안에 들어 있고, `data/`의 JSON으로 옮기는 것이 2단계 첫 작업입니다.
- `backend/`: 코드는 아직 없습니다(4단계에서 구현). API 규격과 가짜 응답만 있습니다.
- `data/`의 JSON은 `widget.js`의 샘플 값을 새 스키마로 옮긴 초안이며, 화면과 아직 연결되어 있지 않습니다.

## 실행 (프론트 데모)
```bash
python -m http.server 8766 --directory frontend
```
http://localhost:8766/demo.html 에서 오른쪽 아래 버튼을 누릅니다. 스크립트나 CSS를 고치면 `demo.html`의 `?v=` 숫자를 올려 캐시를 피합니다.

## 지키는 원칙
- 진단과 추천은 규칙으로 계산하고, AI는 설명 문단에만 씁니다(AI가 꺼져도 동작).
- 비밀 키는 `backend/` 환경변수에만 둡니다. 저장소와 화면 코드에 넣지 않습니다.
- 대상·난이도 정보가 없는 교육은 단정해서 추천하지 않고 "정보 부족"으로 표시합니다.
- 제주AX단 홈페이지 저장본(HTML, 이미지, 스크립트)은 이 폴더에 두지 않습니다. 디자인 복제 범위가 확인되지 않았기 때문입니다.
