# data

화면과 서버가 함께 읽는 공용 데이터입니다. **바꾸기 전에 상대에게 알립니다.**

| 파일 | 내용 | 상태 |
|---|---|---|
| `taxonomy.json` | 막힘 유형 9개, 직군 6개, 활용 단계 0~4, 유료 여부, 진행 방식, 지역, 난이도, 결과 카드 문구 | 가설 v1 (인터뷰 후 확정) |
| `courses.json` | 교육 목록(현재 4건) | 초안, 정보 기준일 2026-11-11 |

- 스키마 설명은 `../docs/개발명세/00_공통_기준.md`(4절 분류 체계, 5절 교육 스키마).
- 두 파일 모두 `schemaVersion`을 가지며, 분류나 필드를 바꾸면 올립니다.
- **현재 `frontend/widget/widget.js`와 연결되어 있지 않습니다.** 위젯 안의 샘플 값을 옮긴 것이라 두 곳이 어긋나지 않게, 연결 전에는 위젯 쪽 값을 고치면 여기도 같이 고칩니다.
- `courses.json`의 4건은 모두 `infoLevel: thin`입니다. 해결하는 막힘 유형, 대상 활용 단계, 수업 후 할 수 있는 것, 난이도, 장소 주소는 확인되지 않았습니다. 확인 없이 채우지 않습니다.
- 접수 마감이 지난 교육(예: 11/11 마감)은 규칙에서 추천 목록에서 제외합니다.
