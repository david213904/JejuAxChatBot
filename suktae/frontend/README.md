# frontend

챗봇 위젯 화면입니다. 자세한 명세는 `../docs/개발명세/01_프론트엔드_명세.md`.

| 경로 | 내용 |
|---|---|
| `demo.html` | 위젯을 불러오는 최소 데모 페이지(실제 홈페이지 사본 아님) |
| `widget/widget.js` | 진단 흐름, 규칙, 화면 (샘플 v4, 한 파일) |
| `widget/widget.css` | 스타일(흑백 + 노랑, 다크 모드, 모바일 전체 화면) |

## 다음 작업 (2단계)
1. `widget.js`를 `config.js`, `flow.js`, `rules.js`, `views.js`, `api.js`로 나누기 (한 사람이 먼저 하고 알림)
2. 질문 선택지와 교육 목록을 `../data/taxonomy.json`, `../data/courses.json`에서 읽기
3. 뒤로 가기, 일정 필터, 공유 문구 복사, 길찾기 링크

## 규칙
- 서버 주소는 설정 파일 한 곳에서만 알고, 비밀 키는 화면에 넣지 않습니다.
- 사용자 입력과 외부 데이터는 `textContent`로만 출력합니다.
- 분류 체계(코드값)는 혼자 바꾸지 않고 `../docs/개발명세/00_공통_기준.md`에 먼저 반영합니다.
