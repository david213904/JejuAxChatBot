# 과제 D 팀 공유: 변경사항 정리 (2026-11-11)

## 한 줄 요약

제주AX단 홈페이지 방문자 중 **AI를 써 봤지만 막힌 사람**에게, 막힌 지점을 짚고 맞는 교육을 처방하는 **컨설팅형 진단 서비스**로 방향을 잡았습니다.

## 1. 정해진 것

| 항목 | 내용 |
|---|---|
| 대상 | 제주AX단 홈페이지 방문자 (AI를 한 번쯤 써 본 사람, **가정이며 인터뷰로 확인**) |
| 관점 | 수준 평가가 아니라 **막힘을 짚고 다음 행동을 처방하는 컨설팅** |
| 진단 길이 | **2분 이내**, 질문 4~5개, 선택형 위주 (자유 입력은 선택) |
| 서비스 흐름 | 막힘 듣기 → 입력 → 진단 → 처방 → 이어가기 (5단계) |
| 구성 방향 | 프론트와 백엔드를 **한 저장소**에서 관리, 교육 데이터(`data/`)는 화면과 챗봇이 함께 사용 |
| 챗봇 | 홈페이지 오른쪽 빈 공간에 챗봇 패널 (역할: 진단, 안내, 교육·위키·오픈채팅 연결) |

## 3. 새로 알게 된 사실 (정정)

- 이전 기획서에 "행사 일정이 비어 있고 추천 교육이 적다"고 썼는데 **틀린 내용**이었습니다 (첫 화면만 보고 판단).
- 실제 `행사 일정` 페이지에는 2026년 11월에 날짜별 1~4개씩, 모두 24건이 올라와 있습니다. 제주AX단 자체 교육뿐 아니라 제주콘텐츠진흥원, 제주경제통상진흥원, 제주산학융합원 등 **외부 기관의 AI 교육·공고도 함께** 올라옵니다.
- 같은 교육이 "접수 시작일"과 "접수 마감일"로 따로 올라온 중복이 많고, 제목만 있어 **대상·난이도·선수 조건은 알 수 없습니다.**
- 아직 고치지 않은 곳: 기획서 12절과 PPT 10번의 "추천할 교육이 적음" 위험 항목

## 4. 논의 중인 아이디어 (문서에는 아직 없음)

1. **막힘 유형 샘플 8개**: 결과가 마음에 안 듦, 뭘 시킬지 모름, 도구 선택 어려움, 쓰다가 끊김, 믿을 수 없음, 반복 작업을 못 넘어감, 보안 걱정, 물어볼 곳 없음 (모두 가설, 인터뷰로 확정)
2. **공용 분류 체계**: 진단 질문의 선택지와 커리큘럼 등록 항목을 같은 목록으로 만들어 직접 매칭
3. **커리큘럼 등록 표준**: 학습 목표, 대상·선수 지식, 사용 도구, 차시, **수업 후 할 수 있는 것**, 난이도·다음 수업. 등록자가 표준 양식으로 쓰고 운영진이 검수
4. **"기타" 서술 수집**: 동의 후 익명으로 저장해 분류 체계를 갱신 (개인정보 안내와 보관 기간 필요)
5. **정보 부족 표시**: 상세 정보가 없는 교육은 단정해서 추천하지 않음
