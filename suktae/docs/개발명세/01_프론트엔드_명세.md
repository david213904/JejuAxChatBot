# 01. 프론트엔드 명세

작성일 2026-11-12 · 상태: 초안 v1 · 먼저 `00_공통_기준.md`를 읽을 것

## 1. 역할
제주AX단 홈페이지 오른쪽 아래에 뜨는 **챗봇 위젯**. 진단 질문을 진행하고 결과 카드, 교육 목록, 교육 상세를 보여 줍니다. 진단과 추천은 **브라우저 안의 규칙**으로 계산하고(서버 불필요), AI 설명 문단만 4단계부터 서버 함수에서 받아 옵니다.

## 2. 현재 상태 (샘플)
위치: `suktae/frontend/` (원본 개발용 `sample/`은 로컬에 그대로 있음)
| 파일 | 내용 |
|---|---|
| demo.html | 위젯만 확인하는 빈 데모 페이지. 홈페이지 사본이 아님 |
| widget/widget.js | 위젯 전체(데이터, 질문, 규칙, 화면)가 한 파일. 약 400줄 |
| widget/widget.css | 흑백+노랑(#ffd84d) 스타일, 다크 모드, 모바일(520px 이하 전체 화면) |

제주AX단 홈페이지 저장본(`index.html`과 `_files` 폴더)은 공개 저장소에 올리지 않습니다. 디자인 복제 범위가 확인되지 않았고 원본 이미지·스크립트가 들어 있기 때문입니다. 홈페이지에 붙여 보려면 로컬에서 저장본의 `</body>` 앞에 `widget/widget.css`, `widget/widget.js`를 연결합니다.

이미 되는 것: 진단 흐름(막힘→직군→단계→유료), 결과 카드, 추천 교육 클릭 시 상세 카드(추천 이유, 정보 부족 경고, 신청 링크), 교육 일정 보기, 창 확대/축소 버튼, 끌어서 크기 조절, 모바일 전체 화면, Esc로 닫기, 사용자 입력은 `textContent`로만 출력.
샘플 한계: 교육 4건이 코드 안에 하드코딩, 자유 입력은 "기타"에서만 사용, 답 수정·뒤로 가기 없음, 저장 없음.

로컬 실행: `python -m http.server 8766 --directory suktae/frontend` → http://localhost:8766/demo.html (스크립트·CSS 수정 시 `demo.html`의 `?v=` 번호를 올려 캐시를 피함)

## 3. 해야 할 일 (우선순위)
### 2단계 (서버 없이 완성)
| 순서 | 작업 | 완료 기준 |
|---|---|---|
| 1 | **파일 분리**: 데이터·질문·규칙·화면을 나눔 (아래 4절) | 한 기능을 고쳐도 다른 사람 파일과 안 겹침 |
| 2 | 질문 선택지와 교육 목록을 `data/*.json`에서 읽기 | 코드 수정 없이 데이터만 바꿔도 반영 |
| 3 | 답변 수정·뒤로 가기 | 이전 질문으로 돌아가 다시 선택 가능 |
| 4 | 교육 일정 필터(무료/온라인/접수 중), 마감 임박(D-n) 표시 | 데이터 항목이 있는 교육만 필터 대상 |
| 5 | 결과 카드 공유 문구 복사 | 단계·막힘·첫 실습이 짧은 글로 복사됨 |
| 6 | 막힘 응급처치 카드, 프롬프트 예시 | 막힘 유형별 2~3개 표시 |
| 7 | 교육 상세에 장소 주소와 **길찾기 링크**(카카오맵/네이버지도) | 온라인 교육은 링크 숨기고 "이동 불필요" |
| 8 | 입문 안내 경로(단계 0) | 단계 0 선택 시 별도 안내 |
| 9 | 정보 부족 표시와 정보 기준일·출처 표시 확대 | thin 교육은 단정 추천 문구 없음 |

### 3단계
- 인터뷰·시연에서 나온 수정을 반영(질문 문구, 선택지, 규칙). 바뀌는 부분은 데이터 파일로 분리되어 있어야 함.

### 4단계 이후
- `POST /api/diagnosis/explain` 호출 → 설명 문단 표시. 실패하면 규칙 결과만 표시.
- 5단계: 로그인, 결과 저장·불러오기, 재진단, 피드백(좋아요/아쉬워요), 기타 서술 동의 화면.

## 4. 파일 분리 제안
```
frontend/
├─ index.html            (샘플 홈페이지 사본)
├─ widget/
│  ├─ widget.js          시작점: 위젯 만들기, 열고 닫기
│  ├─ config.js          API 주소 등 설정 (키 없음)
│  ├─ flow.js            질문 진행 흐름, 뒤로 가기
│  ├─ rules.js           추천 규칙 (pickCourses 등)
│  ├─ views.js           결과 카드, 교육 목록·상세 화면
│  ├─ api.js             서버 호출 (mock 전환 가능)
│  └─ widget.css
└─ mock/                 서버 없이 쓰는 가짜 응답
```
- 파일 분리와 `frontend/` 이동은 **작업 시작 전에 한 사람이 먼저** 끝내고 알립니다(충돌 방지).
- 빌드 도구 없이 여러 `<script>`로 불러오거나, 필요하면 번들러를 도입(팀 합의 후).

## 5. 데이터 읽기
- `data/taxonomy.json`: 막힘·직군·단계 이름, 결과 카드 문구(원인, 활용 방법, 첫 실습, 다음 단계).
- `data/courses.json`: 00번 문서 5절 스키마.
- 화면은 시작할 때 읽어 오고, 읽기에 실패하면 "교육 정보를 불러오지 못했어요. 교육 일정 페이지에서 확인해 주세요."와 일정 페이지 링크를 보여 줌.
- 접수 마감 지난 교육 제외, `status = published`만 노출은 **화면에서도** 한 번 더 걸러 냄.

## 6. 화면 상태 흐름
```
시작 메뉴 ─ 진단 시작 → stuck → (other면 서술) → job → level → paid → 결과 카드
        └ 교육 일정 보기 → 목록(필터) → 교육 상세
결과 카드 → 교육 상세 → 신청 링크 / 길찾기 링크 / 다른 교육 / 다시 진단
```
- 상태(`state`)는 `stuck, job, level, paid, otherText`와 "지금까지 선택 기록(뒤로 가기용)"을 가짐.
- 각 단계는 이전 단계로 돌아갈 수 있어야 하고, 돌아가면 이후 선택은 지움.

## 7. 화면·접근성·보안 규칙
- 창 크기: 기본 380×600, 확대 시 최대 760px/화면 높이, 끌어서 조절(최소 320×420), 520px 이하는 전체 화면(조절 버튼 숨김).
- 키보드: 모든 버튼은 Tab으로 이동, Esc로 닫기, 포커스 표시 유지. 창에 `role="dialog"`.
- 색: 다크 모드 변수 유지, 경고는 빨간 계열(다크 모드 별도 색).
- **사용자 입력과 외부 데이터는 `textContent`로만 출력**(innerHTML 금지).
- 외부 링크는 `target="_blank" rel="noopener noreferrer"`.
- 기타 서술 입력 안내: "이름·회사·연락처는 쓰지 마세요". 5단계에서 저장할 때는 동의 체크를 먼저 받음.
- 화면 코드, 설정 파일, 저장소에 **비밀 키를 넣지 않음**. 화면이 아는 것은 서버 주소뿐.
- 길찾기 링크는 **교육장소만** 넣고 출발지는 지도 앱이 현재 위치로 처리(거주지를 받지 않음). 링크 형식은 만들 때 카카오맵·네이버지도의 현재 규격을 확인.

## 8. 서버 연동 약속
- 호출은 `api.js` 한 곳에서만 합니다. 주소는 `config.js`의 값(`API_BASE_URL`)을 씀.
- 서버가 없거나 개발 중이면 `mock/`의 가짜 응답을 씀(설정 한 줄로 전환).
- 요청·응답 형식은 `02_백엔드_명세.md` 4절을 따름. 형식을 바꾸고 싶으면 백엔드 담당과 먼저 합의.
- 서버 호출이 느릴 때를 위해 "정리하는 중…" 표시와 시간 제한(예: 15초) 후 규칙 결과로 대체. 가능해지면 글자가 나오는 대로 표시(스트리밍).

## 9. 완료 기준 (2단계)
- [ ] AI와 서버 없이 4문항, 2분 이내에 결과 카드까지 도달
- [ ] 교육 데이터를 바꾸면 코드 수정 없이 화면에 반영
- [ ] 뒤로 가기·일정 필터·공유 문구 복사·길찾기 링크 동작
- [ ] 정보 부족 교육에 경고가 보이고 단정 추천이 없음
- [ ] 모바일(375px), 데스크톱, 다크 모드에서 깨지지 않음
- [ ] 콘솔 오류 없음, 키보드만으로 진단 완료 가능

## 10. 하지 않는 것
- 화면에서 AI API를 직접 호출하지 않음.
- 회원 정보·거주지·정확한 주소를 화면에서 수집하지 않음(5단계 이전).
- 홈페이지 원본(사본 `index.html`) 내용은 위젯 연결 줄 외에는 고치지 않음. 실제 사이트 삽입은 운영진 협의 후.
- 분류 체계(코드값)를 혼자 바꾸지 않음. 바꾸려면 00번 문서에 먼저 반영하고 알림.

## 11. 알아 둘 점
- 현재 샘플의 교육 4건과 정보는 **2026-11-11 기준**이고, 제주AX단 외 외부 기관 교육은 제목·접수일·장소만 알려져 있어 `thin`입니다.
- 추천 규칙·문구는 샘플입니다. 인터뷰 후 바뀝니다.
