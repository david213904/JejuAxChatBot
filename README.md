# 제주AX단 길잡이 (JejuAxChatBot)

내 일에 맞는 AI 배움의 순서를 알려 주는 챗봇 서비스입니다. (제주AX단 해커톤 과제, 마감 2026-11-17)

## 서비스 흐름
1. 객관식 5문항으로 AI 친숙도, 막힌 점, 시간, 선호 방식, 쓰는 도구를 조사
2. 지금 하는 일과 이루고 싶은 것을 입력
3. 진단(단계와 막힌 이유) → 제주AX단 교육 추천 → 맞는 교육이 없으면 유튜브 강의 추천
4. 결과 카드: 진단, 추천, 배울 순서, 오늘 해볼 10분 실습, 다음 행동(신청·오픈채팅)

유튜브는 **검증 목록(`data/videos.json`)을 먼저 보고, 부족하면 실시간 검색**합니다.

## 범위
- 만들 것: 객관식 → 입력 → 진단 → 교육 추천 → 결과 카드
- 되면: 유튜브 검증 목록 추천, 10분 실습
- 시간이 남으면: 유튜브 실시간 검색, 교육 정보 자동 갱신
- 제외: 운영자용 집계 화면, 로그인, 재진단 기록 저장, 정원·신청 현황 연동

## 폴더
| 경로 | 내용 | 담당 |
|---|---|---|
| `app/` | 화면 (Next.js App Router) | 개발 |
| `lib/types.ts` | 데이터 파일 형식 정의 | 둘이 합의 후 수정 |
| `data/courses.json` | 제주AX단 교육 정보 | 데이터 |
| `data/videos.json` | 검증된 유튜브 영상 (현재 비어 있음) | 데이터 |
| `data/stages.json` | 단계 진단 기준 (가안) | 데이터 |
| `data/survey.json` | 객관식 문항 (가안, 인터뷰 후 수정) | 데이터 |

데이터 담당은 `data/`만, 개발 담당은 `app/`, `lib/`를 주로 수정하면 충돌이 적습니다.
데이터 형식은 `lib/types.ts`를 보세요. 교육 정보는 사이트 요약을 기준으로 넣은 값이라 **제주AX단 확인이 필요**합니다.

## 실행
```bash
npm install
npm run dev
```
http://localhost:3000 에서 확인합니다.

## 키 관리 (중요)
- `.env.example`을 복사해 `.env.local`을 만들고 키를 넣습니다. `.env.local`은 올라가지 않습니다.
- 배포에서는 Vercel의 Environment Variables에만 넣습니다.
- **API 키를 코드, 이슈, 채팅에 붙이지 마세요.**

## 배포
Vercel에 이 저장소를 Import하면 `main`에 푸시할 때마다 자동 배포됩니다. Framework Preset은 Next.js로 자동 인식됩니다.

## 개인정보 원칙
- 사례와 인터뷰 내용은 본인 동의와 익명 처리를 거친 것만 씁니다.
- 대화에 이름, 연락처를 입력하지 않도록 화면에 안내합니다.
